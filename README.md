# Beautiful_Portfolio

# 🚀 Personal Portfolio Website

Welcome to my personal portfolio website!

This project is a modern, responsive, and interactive portfolio website built using **React.js, Vite, and Tailwind CSS**.

The main purpose of this portfolio is to showcase my:

- 👨‍💻 Programming skills
- 🚀 Projects
- 🎓 Education
- 🧠 Technical knowledge
- 🌱 Learning journey
- 📫 Contact and social profiles

I created this project to build a professional online presence and to demonstrate my frontend development skills.

---

## 🌐 Live Website

🔗 **Portfolio Website:**

https://beautiful-portfolio-nine-amber.vercel.app/

> Replace the above URL with your deployed Vercel URL.

---

## ✨ Features

### 🏠 Home Page

The website contains a main Home page that acts as the central portfolio experience.

It introduces the developer and provides navigation to the different parts of the portfolio.

---

### 👨‍💻 About Section

The About section provides information about me, my interests, learning journey, and goals as a Computer Science student.

It helps visitors understand who I am beyond just my technical skills.

---

### 🛠️ Skills

The portfolio can be used to showcase technical skills such as:

- Java
- C++
- JavaScript
- HTML
- CSS
- React
- Git
- GitHub
- Problem Solving
- Data Structures and Algorithms

The skills section can be updated whenever I learn a new technology.

---

### 🚀 Projects

The Projects section showcases the projects I have created while learning and practicing programming and web development.

Each project can contain:

- Project name
- Project description
- Technologies used
- GitHub repository
- Live demo

This makes it easier for recruiters and developers to understand my practical experience.

---

### 📱 Responsive Design

The website is designed to work across different screen sizes.

It can be viewed on:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile
- 📟 Tablet

Responsive layouts make the portfolio easier to use on different devices.

---

### 🌙 Dark Mode

The project includes a dark-themed visual design.

The CSS defines separate light and dark theme variables for backgrounds, cards, borders, text, and primary colors.

The dark theme uses a deep background with purple primary accents.

---

### ✨ Animated UI

The website contains custom animations to make the interface more interactive.

Some of the animations include:

- ⭐ Floating elements
- 💫 Subtle pulse animation
- 🌌 Meteor animation
- 🎬 Fade-in animations
- ✨ Text glow
- 🖱️ Card hover effects
- 🔘 Button hover effects

The custom CSS defines animations such as `float`, `pulse-subtle`, `fade-in`, and `meteor`.

# 🧰 Technologies Used

## Frontend

### ⚛️ React.js

React is used to build the user interface using reusable components.

The project uses React 19. :contentReference[oaicite:3]{index=3}

---

### ⚡ Vite

Vite is used as the development and build tool.

It provides:

- Fast development server
- Hot Module Replacement
- Fast production builds

The project contains the following Vite commands:

```bash
npm run dev
npm run build
npm run preview
```


🎨 Tailwind CSS

Tailwind CSS is used for styling and responsive design.

The project uses Tailwind CSS 4 with the Vite integration.


🧭 React Router

React Router is used for navigation and routing.

The application currently contains:

Home route
Not Found route

The routing is configured using BrowserRouter, Routes, and Route.
